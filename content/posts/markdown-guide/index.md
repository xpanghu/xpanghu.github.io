这是一篇写作示例，也是一份可以随时翻阅的小指南。本站的文章保存在 `content/posts/`，每篇文章可以拥有自己的文件夹。

## 新建文章

在博客目录中运行：

```sh
hugo new content posts/my-new-post/index.md
```

打开生成的文件，顶部是文章信息：

```yaml
---
title: "我的新文章"
date: 2026-10-24T10:00:00+08:00
draft: true
description: "简短介绍这篇文章。"
tags: [笔记]
---
```

`title` 是文章标题，`description` 是简介，`tags` 用于分类查找。正式发布前，把 `draft` 改成 `false`，并确认日期不是未来时间。

## 组织正文

文章标题已经由顶部信息生成，正文从二级标题 `##` 开始。三级标题 `###` 可以进一步分组，右侧或文章顶部的目录会自动生成。

### 常用格式

用 `**加粗**` 标记重点，用 `*斜体*` 做轻量强调，用反引号标记 `变量名`。段落之间空一行即可。

> 引用用来保留原话。转载和引用他人内容时，记得给出来源链接。

### 清单和表格

| 内容 | 建议记录 |
| --- | --- |
| 问题 | 当时的现象与预期 |
| 过程 | 关键步骤与尝试 |
| 结论 | 解决方法及其适用范围 |

## 展示代码

使用三个反引号包围代码，并标明语言。博客会进行语法高亮，代码块右上角支持复制。

```python
def greet(name):
    return f"你好，{name}！"

print(greet("世界"))
```

## 插入图片

把图片放在文章的 `index.md` 旁边，即可用相对路径引用：

```markdown
![图片的文字说明](photo.jpg)
```

这种方式便于把一篇文章和它的附件一起移动、备份。图片的文字说明也能帮助无法看到图片的读者理解内容。

## 预览与发布

运行 `make dev`，在本地查看文章。此命令包含草稿；正式构建使用 `make build`，默认不发布草稿。

确认文章准备好以后，把 `draft` 改为 `false`，保存并提交到 GitHub 的 `main` 分支。配置好 GitHub Pages 后，仓库会自动生成和发布网站。

你可以在“搜索”中输入 **Markdown** 找到这篇文章，也可以在“标签”和“归档”中浏览它。
