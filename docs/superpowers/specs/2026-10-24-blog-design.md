# 个人博客首版设计

## 目标与依据

参考 https://www.zhouxin.space/logs/ 中的搭建日志，在当前空目录建立可维护的中文个人博客。首版成功标准是：可以本地预览、用 Markdown 新建文章、正常搜索和浏览归档，并有明确的写作说明。

## 方案与取舍

- 采用 Hugo + PaperMod：沿用参考日志的核心方案，用主题已有功能减少维护成本。
- 自建前端会增加文章生成和索引工作；带数据库的博客系统需要额外服务维护，均不作为首版方案。
- 先完成本地版本。上线方式以用户后续选择为准，不假定已有服务器或域名。

## 首版范围

- 中文首页、文章列表、建站日志、搜索、标签、归档、关于页。
- Markdown 写作、文章目录、代码高亮与复制、深浅色切换、RSS。
- 简洁阅读风格；桌面与手机均可使用；不引入外部字体依赖。
- 提供原创示例文章与写作说明，明确标记示例。博客名称暂用“我的博客”，关于页不虚构个人经历或联系方式。
- 优先使用主题原生功能；必要样式通过扩展文件添加，不修改主题源文件。

## 暂不包括

评论、访问统计、收费图床、用户系统，以及需要账户或服务器信息的公开部署。后续有实际需求再接入。

## 验证

1. Hugo 完整构建成功，主要页面、RSS 和搜索索引存在。
2. 页面内部链接与静态资源可以访问，草稿不进入正式输出。
3. 浏览器验证中文搜索、主题切换、文章目录及导航。
4. 检查桌面与手机宽度，无横向溢出。
